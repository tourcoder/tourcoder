前几日，Claude 的开发商 Anthropic 上市了，转头看看 OpenAI，我想起另外两家企业 GitLab 和 GitHub，感觉它们有点像，但后者更纯粹点。最早 GitLab 最早是 GitHub 上的一个开源项目，后来逐步壮大，迁出，然后被投资，独立上市。GitHub “错过”上市机会，最后被微软收购。

Anthropic 也“算是”来自 OpenAI 内部，然后一路走到 IPO，资本结构清晰。相比较而言 OpenAI 就有点“怪胎”了。

- OpenAI 是一种非营利加营利混合的治理结构，这会导致巨头公司不敢轻易出手收购，同时也让其 IPO 变得困难，这导致它可能会在很长的一段时间内一直处于"准上市、准被收购"的模糊地带。

- OpenAI 的潜在买家实在太少了，微软，Meta 和 Oracle。其他的几乎都会是「投资+服务」的模式，而非买下。微软不需要一个模型实验室，比如英伟达，亚马逊，Google 和 Apple。

- OpenAI 现在的压力主要来自 AI 叙事，其公开压力基本会集中在 2027 年中下旬到 2028 年爆发：第一点，Anthropic 已经上市，其财务数据已经成为对照样本，市场会拿 OpenAI 的私募估值跟它比，差距一旦太大，质疑就会变多，而现在 OpenAI 的私募估值差距基本到了质疑的层面；第二点，Stargate UAE 的一吉瓦集群要在 2026 底开始逐步上线，届时算力成本会从数据承诺变真实用量，审计就会带来压力；第三，美国大选周期过去后，监管机构会腾出精力处理 AI 资本结构的问题，要知道国会听证已经开过一轮了。

- OpenAI 有个非常严重的死循环：它在用钱换时间，用时间换稀释，稀释带来的是治理混乱，而治理混乱又推迟上市。这种操作会引起循环融资的质疑：比如，OpenAI 拿微软的钱买英伟达的芯片，英伟达又投 OpenAI，账越滚越大，审计师和监管迟早要问清楚。

- OpenAI 目前最舒服的点是中东等主权基金。他们要的是长期地缘布局，不图两三年的回报，短期不会逼 OpenAI，但这也会是悬在 OpenAI 头上的达摩克利斯之剑。

最后，不排除 OpenAI 可能是因为烧不起钱而被迫卖部分，甚至全部的“核心资产”。
